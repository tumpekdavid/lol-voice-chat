# lol-voice-chat

Discord bot that joins a voice channel, listens for PTT audio, and answers spoken LoL champion-ability questions via the OpenAI Realtime API. See [.claude/CLAUDE.md](.claude/CLAUDE.md) and [docs/](docs/) for architecture and decisions.

## Getting started on a new machine

### 1. Prerequisites (host)

- [Git](https://git-scm.com/downloads)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (running)
- [VS Code](https://code.visualstudio.com/) with the [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

### 2. Clone

```bash
git clone git@github.com:tumpekdavid/lol-voice-chat.git
cd lol-voice-chat
```

### 3. Configure git for the container

The Dev Containers extension auto-copies your host `~/.gitconfig` and auto-forwards your host SSH agent — but only if they're set up on the host first. Do this once per machine.

**Git identity (any OS):**

```bash
git config --global user.name  "Your Name"
git config --global user.email "you@example.com"
```

**SSH agent — Windows (PowerShell):**

```powershell
# Admin PowerShell — enable and start the service
Set-Service ssh-agent -StartupType Automatic
Start-Service ssh-agent

# Normal PowerShell — load your GitHub key (adjust path)
ssh-add $env:USERPROFILE\.ssh\id_ed25519
```

**SSH agent — macOS / Linux:**

```bash
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

Verify the key is loaded: `ssh-add -l`. See the [VS Code guide](https://code.visualstudio.com/remote/advancedcontainers/sharing-git-credentials) for HTTPS credential helpers and GPG signing.

### 4. Environment variables

Create `.env` in the repo root (gitignored). Required vars are listed in [docs/operations.md](docs/operations.md#environment-variables) — minimum: `DISCORD_BOT_TOKEN`, `OPENAI_API_KEY`.

### 5. Open in the devcontainer

In VS Code: **Command Palette → Dev Containers: Reopen in Container**. First build takes a few minutes.

Inside the container, verify git forwarding works:

```bash
ssh -T git@github.com   # should greet you by username
git fetch
```

### 6. First-time Python bootstrap (only if `pyproject.toml` does not yet exist)

`pyproject.toml` is generated by `uv init` and dependencies are resolved by `uv add` (versions picked by the resolver, not hand-pinned). Run once inside the container, then commit `pyproject.toml` and `uv.lock`:

```bash
uv init --bare --no-workspace --vcs none --python 3.12
uv add discord.py discord-ext-voice-recv openai apscheduler httpx
uv add --dev pytest ruff
```

After bootstrap, subsequent container rebuilds run `uv sync` automatically. To change deps later:

```bash
uv add <package>
uv remove <package>
uv sync
```

### 7. Run

See [docs/operations.md](docs/operations.md) for the full command list.

## What the devcontainer provisions

- `mcr.microsoft.com/devcontainers/python:3.12` base.
- [uv](https://docs.astral.sh/uv/) installed via `pip install --user uv` (no `ghcr.io/astral-sh/uv` devcontainer feature exists — the registry path is the uv Docker image, not a feature manifest).
- `libopus0` — required at runtime by `discord-ext-voice-recv` (Opus audio codec). Without it, the bot will fail to decode received voice frames.
- [Claude Code](https://code.claude.com/docs/en/vs-code) VS Code extension. The extension bundles its own `claude` CLI binary, so no separate Node / npm install is needed. Sign in via the extension panel on first use.
- Runs `uv sync` on container create **if** `pyproject.toml` already exists.
