# lol-voice-chat

Discord bot that joins a voice channel, listens for PTT audio, and answers spoken LoL champion-ability questions via the OpenAI Realtime API. See [.claude/CLAUDE.md](.claude/CLAUDE.md) and [docs/](docs/) for architecture and decisions.

## Local development

The project develops inside a VS Code devcontainer (Debian + Python 3.12 + uv). Open the folder in VS Code and choose **Reopen in Container**.

### What the container provisions

- `mcr.microsoft.com/devcontainers/python:3.12` base.
- [uv](https://docs.astral.sh/uv/) installed via `pip install --user uv` (no `ghcr.io/astral-sh/uv` devcontainer feature exists — the registry path is the uv Docker image, not a feature manifest).
- `libopus0` — required at runtime by `discord-ext-voice-recv` (Opus audio codec). Without it, the bot will fail to decode received voice frames.
- Runs `uv sync` automatically on container create **if** `pyproject.toml` already exists.

### First-time bootstrap (inside the container)

`pyproject.toml` is generated by `uv init` and dependencies are resolved by `uv add` (so versions are picked by the resolver, not hand-pinned). Run once, then commit the resulting `pyproject.toml` and `uv.lock`:

```bash
uv init --bare --no-workspace --vcs none --python 3.12

uv add discord.py discord-ext-voice-recv openai apscheduler httpx

uv add --dev pytest ruff
```

### After bootstrap

Subsequent container rebuilds run `uv sync` automatically. To add or remove deps later:

```bash
uv add <package>
uv remove <package>
uv sync
```
